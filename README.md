# Budget Tracker API

Backend-сервис для приложения учета личных финансов.  
Система позволяет пользователям структурировать доходы, расходы, управлять категориями и получать аналитику с авторизацией.

## О проекте

Цель проекта — создать масштабируемый, удобный для поддержки и безопасный REST API для:

- регистрации и входа пользователей
- управления категориями доходов и расходов
- хранения финансовых операций
- получения статистики

## Архитектура

Проект использует **Чистую архитектуру (Clean Architecture)**.

src/main/java/com/example/budget

api/            - REST-контроллеры и DTO  
domain/         - Бизнес-сущности  
application/    - Сервисы и сценарии работы
infrastructure/ - Работа с БД, безопасность, Spring
